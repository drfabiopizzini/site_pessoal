# Site pessoal — Dr. Fábio Pizzini

Página pessoal e profissional do Dr. Fábio Pizzini, Médico do Trabalho e Perito, Assistente Técnico Judicial (FP Perícias Médicas, Sorocaba/SP).

Site estático (HTML, CSS e JavaScript puros), sem etapa de build. Publicado na Vercel.

- `index.html` — conteúdo
- `styles.css` — identidade visual FP (grafite, teal, Noto Serif + Montserrat)
- `script.js` — animações (rede no hero, revelações ao rolar, contadores, linha do tempo, marquee, botões magnéticos)
- `assets/` — logotipos, favicons e imagem de compartilhamento

Para editar textos, altere o `index.html` e faça um novo commit: a Vercel publica automaticamente.
